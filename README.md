# 백약산 3D

**한국 산을 배경으로 약초를 채집하고, 야생동물을 만나며, 다른 등산객과 함께 오르는 브라우저 게임**입니다. PC·모바일을 지원하도록 제작된 Three.js 기반 프로젝트입니다.

**현재 버전:** `v1.2.8` — 공양·황금 호미 멀티플레이 업데이트, 시작 오류 복구 및 황금 5성 7종 원본 모델 일치·황금 재질 개선판. 일반 5성은 음식과 동일한 이동(+32%)·점프(+17.5%) 효과 40분과 산삼 은유 힌트 3% 확률. 황금 5성은 동일한 이동·점프 효과 및 멧돼지·바위 추락·벌 기절 보호 24시간, 특별 칭호는 영구 유지. 기존 촛불·불상 빛·동굴 진동 연출과 눈·모닥불 저음 효과, B번 긴 고음 삭제 유지.

### 이번 수정: 황금 5성 그래픽

- 황금 5성 7종(산삼, 천마, 상황버섯, 송이, 능이, 꽃송이버섯, 석이버섯)은 각 일반 5성의 **동일한 형태·크기·기하 구조**를 사용합니다. 별도 형태의 황금 모델을 만들지 않습니다.
- 일반 식물의 원래 색상 버퍼는 그대로 보존하고, 황금 개체의 복제본에서만 잎·줄기·열매·뿌리의 밝기 차이가 살아 있는 황금색으로 처리합니다. 버섯도 갓·줄기 등의 부위별 명암을 유지합니다.
- 황금으로 설정된 고유 자리와 개체의 실제 품종이 반드시 일치해야 금색으로 나타납니다.
- 도감·가방·채집 성공 안내·불상 공양은 공통의 동일 모델 생성 함수를 사용합니다.
- 채집물의 개수, 생성 자리, 채집 난이도, 기능·저장, 시작 화면·멀티플레이 로직은 변경하지 않았습니다.

## 게임 이용 및 배포

GitHub Pages에서 별도 백엔드 설치 없이 정적 웹사이트로 서비스할 수 있습니다. 실제 배포에 필요한 핵심 파일은 **`index.html`, `dist/game.bundle.js`, `styles/`**이며, 게임 실행 중 Three.js·MQTT 등 기존 외부 CDN과 네트워크 연결을 사용합니다.

### GitHub Pages 업데이트

1. 이 ZIP을 압축 해제해 **파일과 폴더 구조를 그대로** 기존 GitHub 저장소의 최상위에 업로드합니다.
2. 반드시 **`index.html` + `dist/game.bundle.js` + `styles/14-golden-hoe-ui.css`를 세트로 갱신**합니다. 나머지 `styles/`, `src/`, `scripts/`도 덮어쓰세요.
3. 이전 버전에서 루트에 따로 있던 문서 6개(`CHANGELOG.md`, `CODE_MAP.md`, `TEST_REPORT.md`, `POPULATION_REPORT.md`, `SOUND_DESIGN.md`, `SOUND_IDENTIFICATION.md`)는 **GitHub에서 직접 삭제**해야 깔끔한 구조가 됩니다. 새 ZIP 업로드만으로 기존 파일이 자동 삭제되지는 않습니다.
4. 변경 사항을 Commit합니다. 기존의 **Settings → Pages → main / (root)** 배포 설정을 유지하고 반영 후 새로고침하세요. 배포 상태가 업데이트됐는지 확인한 뒤 게임에 접속하세요.
5. 업데이트 전 게임의 **기록 저장**으로 JSON 기록을 백업하는 것을 권장합니다.

> `docs/`와 `src/`, `scripts/`, `reports/`는 개발·문서용 파일입니다. **게임 실행에 필요한 `dist/game.bundle.js`는 삭제하지 마세요.** `backup/`은 초기 원본을 보관한 개발 참고자료입니다.

## 개발 방법

[Node.js](https://nodejs.org/) 18 이상에서 추가 npm 패키지 설치 없이 실행할 수 있습니다.

```bash
npm run dev     # 로컬 개발 서버 + 자동 빌드 (http://localhost:8000)
npm run build   # src/game/의 게임 코드를 dist/game.bundle.js로 결합
npm run check   # 빌드 및 문법·연결 검사
npm test        # 주요 기능 회귀 검사
npm run audit   # 약초·버섯 등 도감 92종의 배치 점검
```

소스 수정은 `src/game/`에서 진행하고, GitHub에 적용하기 전 `npm run build`를 실행해 **`dist/game.bundle.js`를 갱신**하세요. 기존 게임은 `src/game/manifest.json` 순서대로 하나의 스코프로 결합하므로 기능별 JS의 순서를 임의로 바꾸면 안 됩니다.

## 기능 요약

- **탐험:** 등산로, 시간·날씨 변화, 동물, 텐트, 바위 등반, 비밀 동굴
- **채집:** 한국 자생 약초·나물·버섯·열매, 도감, 등급, 5성 감지, 황금 변형
- **상호작용:** 채집물 판매, 모닥불·요리, 가방 확장, 불상 공양·특별 칭호. 일반 5성 공양은 40분 동안 음식과 동일한 이동 +32%·점프 초기 속도 +17.5% 효과와 공양 시 3% 확률의 산삼 은유 힌트를 제공합니다. 황금 5성 공양은 동일한 속도·점프 효과와 멧돼지·바위 추락·벌 기절 보호가 현실 시간 24시간 지속됩니다. 황금 칭호는 24시간이 지나도 영구 유지됩니다. 음식과 공양 효과는 중첩되지 않으며, 활성 시간이 겹쳐도 배율이 증가하지 않습니다.
- **멀티플레이:** 다른 등산객 위치·무전·일부 발견 알림 공유
- **편의:** JSON 기록 저장, 설정에서 지형 새로고침, 모바일 HUD와 나침반
- **음향:** 시간별 숲 소리·동굴 분위기·멧돼지 경고·천둥번개·설원 보행. 설원은 걸음과 분리된 느린 뽀득/삭 텍스처, 눈 위 땅 파기는 낮은 소리, 모닥불은 부드러운 저역 타닥거림. 길게 이어지는 B번 고음은 삭제됨

## 개발 문서

- [CODE_MAP.md](./docs/CODE_MAP.md) — 기능별 소스 전체 목록 및 연결 관계
- [DEVELOPMENT.md](./docs/DEVELOPMENT.md) — 버전 이력, 테스트 결과, 생태·음향 설계, 이전 상세 문서 보존

**중요:** 공양 버프 지속 시간은 실제 시계 기준이며 게임 종료·재접속 이후에도 이어집니다. 황금 가호가 남아 있을 때 일반 공양으로 짧아지지 않습니다. 기절 면역은 시간제이며 칭호는 영구 소유입니다. 3% 산삼 힌트는 공양 완료 때만 추첨하며 정확한 위치는 보여주지 않습니다.

**검증 범위:** 자동 문법/연결 검사와 시뮬레이션 테스트는 제공되지만, 실제 모바일 기기의 WebGL·음향·실시간 멀티플레이 동작은 별도 테스트가 필요합니다.

- 황금 호미 획득 시 전용 축하창, 수호 효과 설명, 산행 계속하기 버튼을 표시합니다.
